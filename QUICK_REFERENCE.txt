================================================================================
                        CLAUDE MODEL DETAILS
================================================================================

Model: claude-3-5-sonnet-20241022
Provider: Anthropic
Type: Large Language Model (LLM)
SDK: anthropic Python package

CAPABILITIES:
✅ Multi-turn conversations
✅ Tool use (automatic function calling)
✅ System prompts (behavior instructions)
✅ Large context (200,000 tokens)
✅ Streaming support

PARAMETERS:
- model: Which Claude model to use
- system: System prompt (tells Claude how to behave)
- tools: Available tools Claude can use
- messages: Conversation history
- max_tokens: Maximum response length

================================================================================
                       TROUBLESHOOTING
================================================================================

❌ "ANTHROPIC_API_KEY not set"
✅ export ANTHROPIC_API_KEY='your_key'

❌ "Connection refused" to FastAPI
✅ Make sure api.py is running on port 8000

❌ "Claude not responding"
✅ Check API key is valid
✅ Check you have API quota

❌ "Tools not being called"
✅ Check Clash Royale API token is valid
✅ Look at error response from Claude

❌ "Timeout errors"
✅ Some analyses take time with multiple tools
✅ Claude may be rate limited

❌ "404 Not Found"
✅ Make sure both FastAPI and Streamlit are running
✅ Check API endpoint spelling
